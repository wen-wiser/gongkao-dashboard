📘 公考看板 · 部署教程

全程网页操作，不用敲命令 · 一次性约 30 分钟 · 之后永远自动运行

整体架构（为什么之后什么都不用管）

☁️ GitHub 服务器
每4小时定时跑→ 🤖 自动巡检官网
公告/职位表/人数→ 📝 生成最新数据→ 🌐 自动发布网页
手机打开即最新→ 💬 微信推送
新公告/快截止

你（搭建者）只需要做第 1~5 步。两位闺蜜什么都不用装，收到网址 → 添加到主屏幕，完事。

1

注册 GitHub 账号（1分钟）

打开 github.com/signup，用邮箱注册。用户名建议用字母（后面网址里会出现它）。

2

创建仓库（2分钟）

  1. 登录后点右上角 + → New repository
  2. 仓库名填：gongkao-dashboard
  3. 选 Public（免费开通网页托管必须选这个）
  4. 点 Create repository
3

上传「考公看板」文件夹里的全部文件（10分钟）

在新仓库页面点 uploading an existing file，然后把 考公看板 文件夹整个拖进浏览器（里面要能看到 index.html、data、scripts、icons、.github 这些）。

⚠️ 如果传完后发现文件列表里没有 .github 文件夹（个别浏览器会忽略点开头的文件夹），手动补建：
点 Add file → Create new file，文件名输入 .github/workflows/update.yml，然后把下面内容完整粘进去，点 Commit：
name: auto-update

on:
  schedule:
    # UTC 0/4/8/12/16/20 点 = 北京时间 8/12/16/20/0/4 点，每天6次巡检
    - cron: '0 0,4,8,12,16,20 * * *'
  workflow_dispatch: {}   # 允许在网页上手动点击运行（测试用）

permissions:
  contents: write

jobs:
  update:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: 安装依赖
        run: pip install requests pyyaml

      - name: 抓取数据
        env:
          PUSHPLUS_TOKEN: ${{ secrets.PUSHPLUS_TOKEN }}
        run: python scripts/fetch_data.py

      - name: 提交更新
        run: |
          git config user.name "auto-update-bot"
          git config user.email "bot@users.noreply.github.com"
          git add data/
          git diff --cached --quiet || (git commit -m "数据自动更新 $(TZ=Asia/Shanghai date '+%Y-%m-%d %H:%M')" && git push)
4

开通网页托管 GitHub Pages（2分钟）

  1. 仓库页点 Settings → Pages
  2. Branch 选 main + /(root)，点 Save
  3. 等 1~2 分钟刷新，页面顶部会出现网址：
    https://你的用户名.github.io/gongkao-dashboard/

手机浏览器打开这个网址，看板就上线了。

5

验证自动更新已在跑（2分钟）

  1. 仓库页点 Actions 标签
  2. 左侧点 auto-update → 右侧点 Run workflow ▾ → Run workflow（手动触发一次测试）
  3. 等 1 分钟变绿 ✅，再打开看板网址，顶部"数据更新于"应该变成了刚才的时间
  4. 之后无需任何操作：每天 8/12/16/20/0/4 点自动巡检 6 次
6

（可选，强烈推荐）微信推送提醒

作用：闺蜜就算几天不看网页，新公告、3 天内截止的事项也会自动推送到微信。

  1. 微信搜索「pushplus 推送加」公众号并关注
  2. 点公众号菜单「激活账号」→ 微信授权，得到一串 token（复制）
  3. 把 token 发给闺蜜，让她也关注该公众号并授权（一人一 token）
  4. 回到 GitHub 仓库：Settings → Secrets and variables → Actions → New repository secret，Name 填 PUSHPLUS_TOKEN，Secret 填刚才的 token
  5. 在 Actions 页手动跑一次 auto-update，微信收到消息即成功
💡 免费版每天可推多条，完全够用。不改也行，看板顶部的倒计时提醒照常工作。
7

发给两位闺蜜：装成 App（每人10秒）

手机操作
iPhone（Safari 打开网址）点底部 分享 按钮 → 添加到主屏幕 → 添加。桌面出现"公考看板"图标，点开是全屏 App
安卓（Chrome/自带浏览器）右上角 ⋮ → 添加到主屏幕（或"安装应用"）

打开后各自点自己的头像标签（闺蜜A / 闺蜜B），选择会记住。看板离线也能打开（显示上次的数据）。

❓ 常见问题

1. 打开看板显示"数据更新于"是很久以前？

去仓库 Actions 页看最近一次 auto-update 是否变红（失败）。常见原因是官网临时改版，属正常现象，下一轮一般自愈；也可手动 Run workflow 重试。

2. 巡检日志里有个别官网"超时"黄标？

正常。部分官网限制境外服务器访问（GitHub 服务器在国外），看板会明确标出哪些源没抓到，这些源的信息仍会出现在"官网入口"里可手动查看。重要源（江苏组织部、安徽考试网等）一般都通。

3. 手机上 GitHub 网页偶尔打不开/很慢？

给看板网址套一层国内加速：注册 Cloudflare（免费）→ Workers & Pages → 创建 Pages → 连接 GitHub 仓库 → 直接部署。得到 xxx.pages.dev 网址，国内访问明显更快。两边数据自动同步，不用维护两份。

4. 想改关注的专业/地区/增减数据源？

改 scripts/sources.yaml（数据源和两位的专业关键词都在里面），在 GitHub 网页上点开文件 → 铅笔图标编辑 → Commit，下一轮巡检自动生效。

5. 职位表什么时候会出现在"岗位"页签？

各省职位表随公告一起发布。脚本发现公告后会自动尝试下载并解析 Excel，按专业匹配；遇到全新表格格式会标「待核对」，此时人工点原文确认一下即可。

6. 忘记配置第 6 步的微信推送？

随时可补，配好后从下一轮巡检开始生效。
